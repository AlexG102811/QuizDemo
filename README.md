# Alex's Quiz Site

A quiz demo application built with HTML, CSS, and JavaScript.

## Features
- 5 quiz questions with instant answer feedback
- Running score display
- Clean, responsive card-based styling

## Getting Started

### Run locally
With Node.js 20 or later installed, run:

```sh
node server.js
```

Then open `http://localhost:5000`.

### Run on Replit
The Replit workflow starts the site automatically. Use the web preview to play.
